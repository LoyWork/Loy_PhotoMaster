# Picturama v2.1.1

- 提供相似照片分组清理：快速扫描查找近似副本，DINOv2 深度扫描查找同场景、不同姿势或构图的照片，由用户手动决定保留和删除。
- 将重复照片清理从设置移到侧栏「相似照片清理」下方，扫描结果在主窗口按组显示，支持预览、逐张保留和移入垃圾桶。
- 相似照片与重复照片各自缓存扫描结果、待删除勾选、扫描选项、分页、展开状态和滚动位置，切换页面后可继续整理。
- 照片移入垃圾桶或删除后，同步更新两个清理页面的缓存；如果某组最后保留的照片被移除，会清空该组的待删除选择，避免整组删除。
- 改善旧后台与新界面不匹配时的扫描错误提示。重复扫描支持进度、取消及文件变化检查。

缓存说明：页面结果保留到应用关闭；重启后需要重新扫描。相似照片的感知哈希、DINOv2 特征和预览缓存会保留在本地，后续扫描可复用未变化照片的特征。新增或恢复的照片需要重新扫描才会加入分组。

照片先移入应用垃圾桶，可恢复；清空垃圾桶后才会删除原文件。

本版验证：40 项前端测试、80 项 Rust 测试（含真实模型测试）、多语言检查和前端生产构建通过，浏览器验证了切页恢复与跨页面清理同步。深度扫描使用本地 CPU 推理，无需上传照片。
