# PhotoMaster v2.3.0

- 程序正式更名为 PhotoMaster，窗口、关于菜单、安装包及七种语言文案同步更新。
- 采用早期 iOS 风格的拟物相册图标：皮革封面、金属护角、真实风景照片与厚纸页；应用、桌面、任务栏、安装器和卸载器使用统一图标。
- 移除设置页原 Picturama 大幅装饰 Logo，保留简洁的 PhotoMaster 版本与更新入口。

安装说明：本版按独立的新应用安装。请先卸载旧版 Picturama，再安装 PhotoMaster；不执行旧版安装记录或快捷方式迁移。已有照片库的数据目录仍保留，不删除原照片。

本版继续提供相似照片扫描、多选收藏/移入垃圾箱和应用内签名更新。
