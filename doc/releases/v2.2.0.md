# Picturama v2.2.0

- 优化相似照片扫描：并行准备、缩小后再计算特征、批量写入缓存，默认使用快速模式，保留深度识别。
- 多选照片后显示「收藏」和「移入垃圾箱」；切换文件夹、收藏、垃圾桶等筛选时立即清空选择。
- 新增应用启动检查更新，以及设置中的「检查更新」；点击下载后显示进度，校验签名后自动安装并重启。
- 修复场景检索中相同向量在距离相同时可能漏匹配的问题。

本机 24 张 1200 万像素 JPEG 测试：快速冷扫描约 12.9→1.9 秒，深度冷扫描约 44→5.5 秒；真实照片库耗时取决于设备和文件格式。

**首次升级说明：**v2.1.1 及更早版本没有更新功能，请手动安装本版本。安装 v2.2.0 后，可在下一次发布新版本时测试应用内自动升级。

验证：49 项前端测试、80 项 Rust 测试（含真实模型推理）、7 种语言检查及前端构建通过。
