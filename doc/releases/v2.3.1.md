# PhotoMaster v2.3.1

- 相似照片与重复照片的每组标题旁新增“整组标记删除”，可将包含未展开照片在内的整组照片标记为待删除，再通过底部确认移入应用垃圾桶；仍可取消选择或改为“只保留这张”。
- 修正照片删除时修改旧状态数组的问题，避免网格布局与照片数据不一致；清空垃圾桶后清除已删除照片的焦点和悬停状态。
- 清空垃圾桶改为先处理原文件，再删除对应图库记录；失败项保留供重试，并显示文件路径与错误原因。已删除且所在目录仍可访问的文件可正常清理记录。
- 数据库删除失败时自动回滚，避免影响后续操作；清空过程中显示忙碌状态并禁止重复点击，完成后刷新图库、文件夹和照片数量。

已安装 PhotoMaster v2.3.0 的用户可在设置中检查更新，下载并安装本版，无需卸载。安装包由 GitHub Actions 构建并签署更新签名。

验证：53 项前端测试、81 项 Rust 测试通过，3 项可选测试未运行；七种语言检查及前端生产构建通过。另一台电脑此前的渲染异常未取得原始日志，仍需实机验证。
